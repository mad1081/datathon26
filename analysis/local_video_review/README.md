# Локальный просмотр датасета

Откройте `index.html` двойным щелчком в Edge или Chrome. Страница читает видео из `../../open/videos/`, не обращается к внешним сервисам и не содержит AI-модели.

Если браузер блокирует локальные скрипты или сохранение для `file://`, запустите из корня проекта `python -m http.server 8765 --bind 127.0.0.1` и откройте `http://127.0.0.1:8765/analysis/local_video_review/`. Сервер слушает только ваш компьютер. Остановить: Ctrl+C в терминале. Прямое открытие файла и этот адрес имеют отдельные хранилища браузера.

1. Начните с 21 уникального положительного ролика. Кнопки ведут к исходной метке и за 5 секунд до/после неё. `Х-4.mov` и `Х-47.mov` объединены, обе метки — 57 и 68 секунд — сохранены.
2. Просмотрите контекст и весь ролик. Для каждого наблюдаемого события добавьте отдельную запись. Разделяйте видимое действие и гипотезу о нарушении правила.
3. Заполните категорию, границы события, наблюдение, проверенный ID/пункт правила и сомнения. Не заполняйте поля предположениями ради полноты.
4. Проверьте 19 уникальных отрицательных роликов. Исходная метка отображается как метка организатора, а не вывод автоматического анализа.
5. Отметьте статус проверки и экспортируйте JSON. Разметка хранится в localStorage текущего браузера; экспорт — отдельная резервная копия на диске. Очистка данных браузера может удалить localStorage. Хранилище для прямого открытия файла может зависеть от браузера и пути.

Формат MOV и H.264 поддерживаются не всеми сочетаниями браузера/операционной системы. Реальное декодирование на этой машине пока не проверено. Если видео не запускается, откройте исходник локальным видеоплеером и заполните форму вручную. Альтернатива после установки FFmpeg — локальный remux в MP4 без перекодирования, например `ffmpeg -i input.mov -c copy -movflags +faststart output.mp4`; это создаёт дополнительный файл и потребует указать его в странице. Автоматический remux здесь не выполняется.

Обновление манифеста после нового аудита: `python analysis/local_video_review/build_manifest.py` из корня проекта. Проверяются существование файлов, число уникальных видео и сохранение исходных меток.

Не загружайте экспортированные наблюдения, видео или кадры в облачные AI-сервисы: кейс запрещает такую обработку. Этот инструмент предназначен для локальной работы человека или последующей локальной обработки.

Проверено при создании: 40 уникальных SHA-256, 42 исходных файла, все пути существуют, 21 положительный и 19 отрицательных уникальных роликов, сохранены оба таймкода положительного дубликата; JavaScript прошёл `node --check`. Попытка автоматического запуска Chrome в ограниченной среде завершилась ошибками доступа и GPU-процесса, поэтому воспроизведение и полный сценарий в браузере здесь не проверены. Смысловой просмотр видео не выполнен.
